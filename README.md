# StreamerLive-Bot

## Feature List

- take in chat amount for distributing levels for streamer,
- allows people to sign up for raid train,
- if you have less than level three in chat you can't join the train,
- same features as __r3dlabs__ for signing up for train and scheduling,
- Same features with the in twitch chat operation,
- allow to see streamers in a calendar view,
- keep up with the three free slots before meeting requirements
- post advertisement for the current viewer on train

## Requirements

- API Interactions
  - Twitch
  - Discord
  - Google Calendar
- Database
  - Supabase
- Authentication
  - OAuth2
- Programming Languages
  - JavaScript

## UI Stack

- Frontend
  - React
  - Tailwind CSS
